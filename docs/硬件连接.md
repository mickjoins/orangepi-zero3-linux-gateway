# Orange Pi Zero 3 硬件连接与引脚排查

## 1. 重要提示

Orange Pi Zero 3 的不同 Linux 镜像（Armbian、Debian、Ubuntu、Orange Pi OS）之间，
设备树和引脚映射可能存在差异。**烧录后请先在板子上执行以下命令**，再按实际结果修改
`/etc/orangepi/opiz3-gateway.conf`：

```bash
# 查看 GPIO 控制器与引脚号
cat /sys/kernel/debug/pinctrl/*/pinmux-pins | head
ls /dev/gpiochip*
which gpioinfo && gpioinfo   # 需要 gpiod 工具，可用 sudo apt install gpiod

# 查看 I2C 控制器
ls /dev/i2c-*
i2cdetect -l

# 查看串口设备
ls -l /dev/ttyS* /dev/ttyUSB* 2>/dev/null
```

---

## 2. 默认配置对应的接线

| 外设 | 信号 | 默认值 | 建议接法 |
|---|---|---|---|
| 状态 LED | PC5（Allwinner 全局编号 69） | `led_line=69` `led_active_low=1` | 3.3V -> 330Ω -> LED 阳极 -> 开发板 GPIO 引脚，低电平点亮 |
| 按键 | PC6（Allwinner 全局编号 70） | `button_line=70` `button_active_low=1` | 按键一端接 GPIO，另一端接 GND；启用内部上拉 |
| AHT20 | I2C1 | `i2c_bus=/dev/i2c-1` | VCC->3.3V，GND->GND，SDA->I2C1 SDA，SCL->I2C1 SCL |
| USB-TTL | UART | `uart_dev=/dev/ttyS1` `uart_baud=115200` | 板 TX -> 转换器 RX，板 RX -> 转换器 TX，GND->GND，3.3V 电平 |

> 本程序是应用层软件，GPIO 编号与具体排针位置的对应关系请以
> **Orange Pi Zero 3 用户手册** 和实际 Linux 设备树为准。常见的 Allwinner 计算方式是
> `全局编号 = bank号 × 32 + 引脚号`，例如 `PC5 = 2×32 + 5 = 69`。

## 3. 在板子上快速验证

### 3.1 验证 GPIO

用内核自带的 gpio 工具（如果能安装 gpiod）：

```bash
sudo gpioset gpiochip0 69=0   # 按上表接线时点亮
sudo gpioset gpiochip0 69=1   # 按上表接线时熄灭
```

如果 `gpiochip0` 找不到 69 号，试试其他 chip：

```bash
for c in /dev/gpiochip*; do echo "== $c"; sudo gpioinfo "$c" | head -20; done
```

芯片通常编号为 `/dev/gpiochip0`。如果内核按 bank 拆分 gpiochip（例如 gpiochip0=PA/PB，
gpiochip1=PC...），则需要把 `gpio_chip` 改成对应 chip 编号，`led_line`/`button_line`
改成 bank 内偏移。例如：PC5 在某类镜像下是 `gpio_chip=2 led_line=5`。

### 3.2 验证 I2C

```bash
sudo apt install i2c-tools
i2cdetect -l            # 哪条总线可用
i2cdetect -y 1          # 扫描总线 1，应看到 0x38
```

如果 AHT20 不在总线 1，修改 `i2c_bus`。

### 3.3 验证串口

```bash
# 方法 1：短接 TX/RX 后用 picocom/echo 测试
sudo apt install picocom
sudo picocom -b 115200 /dev/ttyS1
# 在串口助手中发送 hello，应该能看到程序的 /api/serial 输出最新行
```

如果板载 debug 串口为 `ttyS0`，而排针上的 UART 是 `ttyS5` 或其他，修改 `uart_dev`。
必要时使用 `armbian-config` / `orangepi-config` 打开 UART overlay。

## 4. 常见问题

### 4.1 `gpio_dev_init` 失败

- 确认 `/dev/gpiochipN` 存在；
- 确认当前用户有读写权限（服务一般以 root 运行）；
- 6.7+ 新内核可能移除 sysfs GPIO 回退路径，此时只能使用字符设备后端；
- 极旧镜像如果没有 `/dev/gpiochipN`，则依赖 `/sys/class/gpio`，需内核打开 `CONFIG_GPIO_SYSFS`。
- sysfs GPIO 接口不能请求内部上拉；如果按键接地，须外接上拉电阻或通过设备树设置上拉。

### 4.2 传感器读不到

- AHT20 上电后需要时间，程序默认会发送初始化并等待；
- 用万用表确认 3.3V/GND；
- `i2cdetect` 看不到 0x38 说明线序/总线错误；
- 有些 AHT20 模块 I2C 地址焊接为 0x39（很少见），需修改 `i2c_sensor.c` 中的地址宏。

### 4.3 串口无数据

- 短接 TX/RX 后用 `picocom` 验证回显；
- 确认设备树已启用 UART；
- 检查波特率是否与外部设备一致。

---

## 5. 低功耗建议（可选）

- 不接显示器/HDMI 可显著降低功耗；
- Orange Pi Zero 3 本身适合 7×24 轻量网关，传感器采集周期建议 ≥ 2 秒；
- 如果使用电池供电，可在软件中增加空闲降频策略（本项目未实现）。
